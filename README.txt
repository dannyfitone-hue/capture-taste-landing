CAPTURE & TASTE — MENU & SERVICE UPDATE (VERSION 2)

This ZIP contains the updated landing page and its existing styles, script,
logos, and background images.

HOW TO APPLY
In your existing Capture & Taste website project, replace index.html with
this version. The other website files are included for completeness.
Keep your existing server files, project configuration, and environment
settings. Deploy the updated existing project when you are ready.

BOOKING & EMAIL
The form still submits to your existing /api/book service. That server-side
service and email settings cannot be downloaded from the public website and
are not included in this ZIP. This is an update bundle for your existing
project, not a standalone replacement for its booking backend. Uploading
only this ZIP as an entirely new project will not restore booking emails.
